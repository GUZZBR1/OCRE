# Regras do projeto OCRE

- Mantenha dentro desta pasta tudo o que for criado ou usado exclusivamente pelo projeto OCRE: código, documentação, configurações, branches e referências Git, worktrees, issue artifacts, scripts, logs, arquivos temporários, builds, dependências locais e outros artefatos.
- Não crie pastas, arquivos, worktrees ou checkouts do OCRE fora da raiz deste repositório (`projetos/OCRE`). Para worktrees, use uma subpasta como `.worktrees/<nome>` dentro desta raiz.
- Não misture arquivos ou dados de outros projetos nesta pasta.
- Preserve dados existentes. Antes de criar ou mover algo, verifique se já existe; não apague nem sobrescreva conteúdo sem autorização explícita.
- Ao usar ferramentas que aceitam diretório de trabalho, execute-as a partir desta raiz ou de uma subpasta dela.
